# Historical source archive

The files in this folder preserve the original 36-route source dataset and its
supporting business notes for recovery and traceability. They are intentionally
unchanged and are not loaded by the web application.

The active, validated runtime workbook is `../data/workbook.xlsx`. It contains
33 routes after removing `SH0908-1001`, `SH0908-1075`, and `SH0908-1085`, along
with all of their dependent orders, work IDs, items, and replay rows.

Use the active workbook for application results and Excel/Python parity checks.
Use this folder only when historical comparison or recovery is required.
